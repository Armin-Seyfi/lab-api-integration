# Lab Summary

The main challenge was adapting the lab's NewsAPI/Anthropic examples to our AskNews/Cohere setup and making failures observable without unnecessary live API calls. I separated news retrieval, provider calls, and orchestration; added fallback and error handling; then used mocked tests to find and fix an unexpected Cohere sentiment format. I learned that a successful API response does not guarantee valid output, and that rate limiting and spending controls solve different problems. The application now streams LLM responses under a local request limit and a persistent estimated daily budget. A next improvement would retain article-level sources and evaluate factual accuracy, since the current tests establish workflow behavior rather than the truth of a generated summary.
